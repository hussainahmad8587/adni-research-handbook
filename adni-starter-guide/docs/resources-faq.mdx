## FAQ

### I have data. Why do I have more rows than participants?
An export can contain multiple rows per person, including visits, scans, or assessments. Check its row grain and count unique, documented participant IDs. See [chapter 05](/data-structure).


### Can I use ChatGPT / an LLM / a cloud notebook on ADNI data?
Use fictional inputs for public AI tools and cloud demos. Review the DUA’s Appendix A and institutional policy before using any AI-assisted workflow with authorized data.


### Which diagnosis column should I use?
First decide whether you need a fixed baseline group or diagnosis at a specific visit. Then find the documented field in your export. See [pitfall 5](/pitfalls).


### My numbers differ from a published paper. Is something wrong?
Compare the release version, phases, eligibility rules, QC, and measurement methods with the paper.


### Do I need to cite this guide?
Please don't cite it in place of ADNI. Cite ADNI and the primary pipelines per [chapter 08](/publication-policy). Citing the guide as a tutorial is optional ([CITATION.cff](https://github.com/hussainahmad8587/adni-research-handbook/blob/main/adni-starter-guide/CITATION.cff)).


### I found an error in this guide.
Thank you! Open an issue using the "Content error" template, or send a PR. See [chapter 12](/contributing).
