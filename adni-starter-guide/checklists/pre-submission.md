# Pre-submission checklist

See [publication policy and sharing](../docs/08-publication-policy.md) before submitting.

- [ ] I checked the DUA’s rules for this output type.
- [ ] I used the required byline, contributor statement, methods wording, and funding acknowledgment where applicable.
- [ ] For a manuscript, I followed the current DPC submission instructions and completed administrative review before journal submission.
- [ ] Public files contain zero participant-level material, including ID lists and notebook outputs.
- [ ] I documented phases, download dates, exports, acquisition or assay details, exclusions, and missing data.
- [ ] I recorded the publication as required by the current instructions.
